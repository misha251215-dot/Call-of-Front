Сначала выбери папку для игры

Создай отдельную папку «Call on Front». Здесь появится или обновится index.html. Другие HTML-файлы обновлялка не трогает. Разрешение нужно только на эту папку.

Установленная версия пока неизвестна.

В этой папке пока нет отдельного файла профиля. Если у тебя есть старый прогресс, открой Call on Front → «Экспорт профиля». Сохрани JSON в надёжное место. После установки импортируй его в новую игру и нажми там «Папка прогресса».
Проверяю полочку…

Источник: только твой сайт. Кнопка обновления ничего не устанавливает без выбранной папки.

Доступно обновление

    Если сайт скачивается плохо, выбери index.html из распакованного комплекта нужной версии. Это не сохранение JSON. Проверка файла и резервные копии останутся такими же. Сначала проверим скачанный файл и сделаем резервные копии. Прогресс/profile.json не заменяется обновлением.

    Готово! Профиль на месте

    Открой index.html в выбранной папке. В игре нажми «Папка прогресса». При первом переносе старого профиля импортируй его JSON кнопкой «Импорт профиля» в меню игры.

    Не перепутай с игрой на сайте: установленная копия лежит на твоём компьютере.

    Что происходит под капотом?
    Никаких паролей, аккаунтов и платежей внутри обновлялки.

    Папка «Резервные копии» хранит старые версии игры и копии профилей. Не удаляй её, пока не проверишь новую версию. Обновлялка не отправляет твои сохранения в интернет.

    Нет интернета? Уже установленная игра всё равно работает. Для записи файлов нужен Chrome или Edge на компьютере; браузер может снова попросить разрешение. «Пип» может прозвучать только после взаимодействия со страницей.
